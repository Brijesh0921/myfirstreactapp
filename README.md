# myfirstreactapp
Project from IBM Full Stack Developer Professional Certificate on Coursera, built using React and Create React App.

## 🤝 Contributing

Thank you for your interest in contributing!

- You are welcome to **fork** this repository and make your own changes.
- If you want to suggest improvements, you can submit a **pull request (PR)** — I will review it and decide whether to merge.
- Only **approved collaborators** can push directly to the main repository.

If you have any questions, feel free to open an **issue** on GitHub.

Thanks for helping improve this project!
